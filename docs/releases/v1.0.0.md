# JetCutter v1.0.0 リリースノート

**リリース日**: 2026年1月2日

JetCutterの最初の安定版リリースです。動画の無音区間とフィラー（「あー」「えっと」等）を自動検知し、ジェットカット用のタイムラインを生成します。

---

## 主要機能

### macOS ネイティブGUI

PyObjC + AppKitによる完全ネイティブなmacOSアプリケーションを提供します。

- **3タブ構成**: 処理・設定・結果の明確な分離
- **リアルタイム進捗表示**: 処理状況をプログレスバーで可視化
- **処理時間表示**: 結果タブでMM:SS.SS形式の処理時間を表示

```bash
# GUIの起動
jetcutter gui
```

### Final Cut Pro対応

FCPXML v1.10形式でタイムラインを出力し、Final Cut Proに直接インポートできます。

- **DTD完全準拠**: Apple公式仕様に完全準拠
- **非標準タイムコード対応**: DJIドローン等の00:00:00:00以外で開始する動画に対応
- **自動FPS検出**: 動画のフレームレートを自動検出

```bash
# FCPXMLの生成
jetcutter export input.mp4 -o timeline.fcpxml

# FCPXMLの検証
jetcutter validate timeline.fcpxml
```

### DaVinci Resolve対応

Scripting APIを使用してDaVinci Resolve Studioと直接連携します。

- タイムラインの自動生成
- セグメント情報の直接適用

**注意**: DaVinci Resolve Studio版が必要です（無料版はScripting APIに非対応）

```bash
# DaVinci Resolveへの直接出力
jetcutter process input.mp4
```

### 無音区間自動検知

pydubライブラリによる音量ベースの無音検知を実装しています。

| パラメータ | デフォルト値 | 説明 |
|-----------|-------------|------|
| しきい値 | -40dB | この値以下を無音と判定 |
| 最小無音時間 | 300ms | この時間以上の無音を検出 |

### フィラー自動検知

faster-whisperによるAI音声認識でフィラーワードを自動検出します。

- **日本語フィラー対応**: 「あー」「えっと」「まあ」「うーん」等
- **カスタム辞書**: `config/fillers.yaml`で独自のフィラーを追加可能
- **GPU/CPU自動選択**: CUDAが利用可能な場合は自動でGPUを使用

### CLIツール

typerベースの直感的なコマンドラインインターフェースを提供します。

| コマンド | 説明 |
|---------|------|
| `jetcutter gui` | GUIアプリケーションを起動 |
| `jetcutter process` | 動画を処理（DaVinci Resolve出力） |
| `jetcutter analyze` | 解析のみ実行 |
| `jetcutter export` | FCPXML形式で出力 |
| `jetcutter validate` | FCPXMLを検証 |

### Briefcaseパッケージング

macOS向けの.appバンドル生成に対応しています。

```bash
# アプリケーションのビルド
briefcase build macOS

# アプリケーションの実行
briefcase run macOS
```

## 修正内容

### タブ切り替え問題

SettingsTabControllerに`@property`デコレータが欠落していたため、設定タブへの切り替えが正常に動作しませんでした。

### マルチプロセス新規ウィンドウ問題

Briefcaseでパッケージ化したアプリで、文字起こし処理（50%時点）に新しいウィンドウが開く問題を修正しました。

- **原因**: `multiprocessing`のデフォルト開始方式が`spawn`のため、新しいPythonプロセスがGUIを起動
- **解決**: 開始方式を`fork`に変更し、`if __name__ == "__main__"`ガードを追加

### FCPXML 1.10 DTD準拠

- `asset`要素への`src`属性直接設定を`media-rep`子要素に変更
- `format`要素に必須の`name`属性を追加

### GUIデッドロック問題

複数スレッドからの同時アクセスでデッドロックが発生する問題を、`threading.Lock`から`RLock`への変更で解決しました。

## インストール

```bash
# リポジトリのクローン
git clone https://github.com/a2chub/jetcutter.git
cd jetcutter

# 依存関係のインストール
uv pip install -e ".[gui]"

# ffmpegのインストール（未インストールの場合）
brew install ffmpeg
```

---

## 既知の制限事項

- GUIはmacOS専用です（CLIはクロスプラットフォーム）
- DaVinci Resolve連携にはStudio版が必要です
- 非常に長い動画（2時間以上）では処理時間が長くなる場合があります
