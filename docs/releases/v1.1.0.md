# JetCutter v1.1.0 リリースノート

**リリース日**: 2026年1月2日

ライセンスコンプライアンス対応とAboutダイアログを追加したマイナーアップデートです。DMG形式での配布に必要なライセンス文書を整備しました。

---

## 新機能

### Aboutダイアログ

アプリケーションメニューに「About JetCutter」を追加しました。

- **バージョン情報表示**: 現在のアプリバージョンを確認可能
- **ライセンス情報表示**: MITライセンスとサードパーティライセンス情報
- **GitHubリンク**: プロジェクトリポジトリへのリンク

メニューバー → JetCutter → About JetCutter から表示できます。

### ライセンスコンプライアンス対応

DMG形式での配布に必要なライセンス文書を整備しました。

| ファイル | 内容 |
|---------|------|
| `LICENSES/MIT.txt` | MITライセンス全文 |
| `LICENSES/LGPL-3.0.txt` | GNU LGPL v3.0全文 |
| `LICENSES/GPL-3.0.txt` | GNU GPL v3.0全文 |
| `THIRD_PARTY_LICENSES.md` | 全依存パッケージの帰属表示 |

#### PySimpleGUI4 LGPL-3.0遵守

PySimpleGUI4はLGPL-3.0ライセンスで配布されています。本リリースでは以下の遵守要件を満たしています：

- ライセンス全文の同梱（`LICENSES/LGPL-3.0.txt`）
- 著作権表示（`THIRD_PARTY_LICENSES.md`）
- ソースコード取得先の明記
- ライブラリの置換可能性の維持（Briefcaseの独立配置方式により自動的に満たす）

---

## 変更点

### pyproject.toml

Briefcaseのresources設定を更新し、ライセンスファイルをアプリバンドルに含めるようになりました。

```toml
[tool.briefcase.app.jetcutter]
resources = [
    "LICENSES",
    "THIRD_PARTY_LICENSES.md",
]
```

## アップグレード方法

```bash
# リポジトリの更新
git pull origin dev

# 依存関係の再インストール
uv pip install -e ".[gui]"

# アプリの再ビルド（オプション）
briefcase update macOS app
briefcase build macOS app
```
