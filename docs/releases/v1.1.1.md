# JetCutter v1.1.1 リリースノート

**リリース日**: 2026年1月2日

PySimpleGUI4レガシーコードの完全削除と依存関係簡素化のためのパッチリリースです。

---

## 変更概要

このリリースでは、PyObjC + AppKitベースの新GUIに完全移行したことに伴い、使用されなくなったレガシーコードと依存関係を削除しました。

### 主な変更点

- **コードベース簡素化**: 約2,151行のレガシーコードを削除
- **ライセンス統一**: 全依存関係がMITライセンスに統一
- **ビルドツール統一**: Briefcaseに完全移行

---

## 削除されたもの

### レガシーGUIコード

`src/jetcutter/gui_legacy/` ディレクトリ全体を削除しました。

| ファイル | 内容 |
|---------|------|
| `__init__.py` | パッケージ初期化 |
| `app.py` | PySimpleGUI4メインアプリケーション |
| `constants.py` | UI定数 |
| `handlers.py` | イベントハンドラ |
| `processing.py` | 処理ロジック |
| `window.py` | ウィンドウ定義 |

### 依存関係

| 削除されたパッケージ | ライセンス |
|---------------------|----------|
| PySimpleGUI4 | LGPL-3.0 |

### 設定ファイル

| ファイル | 内容 |
|---------|------|
| `setup_gui.py` | py2app用ビルド設定（Briefcaseに統一） |
| `LICENSES/LGPL-3.0.txt` | LGPLライセンス全文 |
| `LICENSES/GPL-3.0.txt` | GPLライセンス全文 |

## アップグレード方法

```bash
# リポジトリの更新
git pull origin dev

# 依存関係の再インストール（オプション）
uv pip install -e ".[gui]"

# アプリの再ビルド（オプション）
uv run briefcase update macOS app
uv run briefcase build macOS app
```

## 謝辞

PySimpleGUI4は長らくJetCutterのGUI開発を支えてきました。PyObjC + AppKitへの移行完了により、よりネイティブなmacOS体験を提供できるようになりました。
