# システム要件定義書：DaVinci Resolve 自動編集エージェント

## 1. システム概要

本システムは、DaVinci Resolve (以下DR) と外部のPython環境を連携させ、動画内の**無音区間**および**不要な発話（フィラー）**を自動で検知・削除し、最適なジェットカット済みのタイムラインを生成する自動編集ソフトウェアである。

### 1.1 目的
- 動画編集作業の効率化
- 無音区間とフィラー（「あー」「えっと」等）の自動削除
- 高品質なジェットカット編集の自動化

### 1.2 対象ユーザー
- DaVinci Resolve Studioを使用する動画編集者
- YouTube/Vlogなどのトーク動画を制作するクリエイター

## 3. 機能要件 (Functional Requirements)

| ID    | カテゴリ | 機能名               | 詳細仕様                                                                             |
|-------|----------|----------------------|--------------------------------------------------------------------------------------|
| F-01  | 解析     | 無音検知機能         | 指定したdB（しきい値）以下の区間を「無音」としてミリ秒単位で特定する。               |
| F-02  | 解析     | フィラー検知機能     | Whisper等のSTTを用い、単語単位のタイムスタンプを取得。「あー」「えっと」等の特定ワードを検知する。 |
| F-03  | 解析     | 保持区間算出ロジック | 無音区間とフィラー区間を除外し、クリップとして残すべき開始・終了時間のリストを生成する。 |
| F-04  | 編集     | DR連携機能           | DRのScripting APIを呼び出し、メディアプールの素材から特定区間をタイムラインへ順次配置する。 |
| F-05  | 編集     | カットマージン設定   | カットの継ぎ目を自然にするため、有音区間の前後にミリ秒単位の遊び（バッファ）を付加する。 |
| F-06  | 制御     | 一括処理 (Batch)     | フォルダ内の複数動画に対して、解析からタイムライン生成までを連続実行する。           |

### 3.1 F-01: 無音検知機能

#### 入力
- 音声ファイル（WAV形式推奨）
- しきい値（dB）: デフォルト -40dB
- 最小無音期間（ミリ秒）: デフォルト 300ms

#### 出力
```python
[
    {"start_ms": 0, "end_ms": 1500, "type": "silence"},
    {"start_ms": 5200, "end_ms": 6800, "type": "silence"},
    ...
]
```

#### 処理フロー
1. 音声ファイルをロード
2. 音量レベル（RMS/dBFS）を計算
3. しきい値以下の連続区間を検出
4. 最小無音期間でフィルタリング

---

### 3.2 F-02: フィラー検知機能

#### 入力
- 音声ファイル
- フィラー辞書（YAML/JSON形式）

#### フィラー辞書の例
```yaml
fillers:
  - あー
  - えー
  - えっと
  - うーん
  - まあ
  - なんか
  - その
  - あのー
```

#### 出力
```python
[
    {"start_ms": 2100, "end_ms": 2450, "type": "filler", "word": "えっと"},
    {"start_ms": 8300, "end_ms": 8600, "type": "filler", "word": "あー"},
    ...
]
```

#### 処理フロー
1. faster-whisperで音声を文字起こし
2. word-level timestampsを取得
3. フィラー辞書とマッチング
4. 該当区間をリスト化

---

### 3.3 F-03: 保持区間算出ロジック

#### 入力
- 無音区間リスト
- フィラー区間リスト
- 動画の総時間
- マージン設定（前後のバッファ）

#### 出力
```python
[
    {"start_ms": 0, "end_ms": 5200, "type": "keep"},
    {"start_ms": 6800, "end_ms": 8300, "type": "keep"},
    ...
]
```

#### アルゴリズム概要
1. 無音区間とフィラー区間をマージ（重複を統合）
2. 削除区間の補集合として保持区間を算出
3. マージンを適用（保持区間の前後を拡張）
4. 隣接する保持区間が接触・重複した場合は結合

---

### 3.4 F-04: DR連携機能

#### 前提条件
- DaVinci Resolve Studio（有料版）がインストールされていること
- 外部スクリプティングが有効化されていること

#### 処理フロー
1. DR Scriptingエンジンへ接続
2. プロジェクトマネージャからプロジェクトを取得/作成
3. メディアプールに素材をインポート
4. 新規タイムラインを作成
5. 保持区間に基づきクリップを配置

---

### 3.5 F-05: カットマージン設定

#### パラメータ
| パラメータ名       | デフォルト値 | 説明                           |
|--------------------|--------------|--------------------------------|
| `margin_before_ms` | 100          | 有音区間開始前のバッファ（ms） |
| `margin_after_ms`  | 100          | 有音区間終了後のバッファ（ms） |

---

### 3.6 F-06: 一括処理 (Batch)

#### 入力
- 入力フォルダパス
- 出力プロジェクト名（オプション）
- 共通設定（しきい値、マージン等）

#### 処理フロー
1. フォルダ内の動画ファイルを列挙
2. 各ファイルに対してF-01〜F-05を順次実行
3. 処理結果をログに記録
4. 全ファイル処理完了後にサマリーを出力

## 4. 非機能要件 (Non-functional Requirements)

| ID    | カテゴリ   | 項目             | 目標・制約条件                                                                      |
|-------|------------|------------------|------------------------------------------------------------------------------------|
| NF-01 | パフォーマンス | 解析速度         | GPU加速（CUDA等）を利用し、動画実時間よりも短い時間で解析を完了させること。         |
| NF-02 | 正確性     | タイムスタンプ精度 | 映像と音声のズレを防ぐため、フレームレート(FPS)に基づいた正確なフレーム算出を行うこと。 |
| NF-03 | 拡張性     | カスタム辞書     | カット対象とするフィラー単語（口癖など）を外部のJSON/YAMLファイルから定義可能にすること。 |
| NF-04 | 環境制約   | DR版数制限       | 外部制御を行うため、原則としてDaVinci Resolve Studio（有料版）を対象とする。         |
| NF-05 | 保守性     | ログ出力         | 解析結果およびAPIの呼び出し結果をログ保存し、エラー時の追跡を可能にすること。         |

### 4.1 パフォーマンス要件詳細

| 項目                   | 目標値                  |
|------------------------|------------------------|
| 解析速度（GPU使用時）  | 実時間の0.3倍以下      |
| 解析速度（CPU使用時）  | 実時間の1.0倍以下      |
| メモリ使用量           | 8GB RAM以下           |
| 同時処理ファイル数     | バッチ時は逐次処理      |

### 4.2 対応フレームレート

| フレームレート | 1フレームあたりの時間 |
|----------------|----------------------|
| 23.976 fps     | 41.708 ms            |
| 24 fps         | 41.667 ms            |
| 25 fps         | 40.000 ms            |
| 29.97 fps      | 33.367 ms            |
| 30 fps         | 33.333 ms            |
| 50 fps         | 20.000 ms            |
| 59.94 fps      | 16.683 ms            |
| 60 fps         | 16.667 ms            |

## 7. 制約事項・前提条件

### 7.1 システム要件
| 項目      | 最小要件                            | 推奨要件                            |
|-----------|-------------------------------------|-------------------------------------|
| OS        | Windows 10/11, macOS 11+, Linux    | 同左                                |
| RAM       | 8GB                                 | 16GB以上                            |
| GPU       | CUDA対応GPU（オプション）           | NVIDIA RTX 30xx以上                 |
| ストレージ| SSD 50GB以上の空き容量              | NVMe SSD 100GB以上                  |

### 7.2 ソフトウェア要件
- DaVinci Resolve Studio 18.0以上
- Python 3.10以上
- ffmpeg（システムにインストール済み）

### 7.3 制限事項
1. DaVinci Resolve無料版では外部スクリプティングが制限される
2. 音声認識精度は音質・話者の明瞭さに依存
3. 複数話者の同時発話には対応しない（初期バージョン）
