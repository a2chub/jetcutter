JetCutterは、動画の無音区間とフィラーを自動検知し、
ジェットカットを瞬時に生成。あなたの編集時間を80%削減します。

あなたの才能は、そんなことのためにあるのではありません。

AIが単調な作業を引き受けます

JetCutterは、動画を投げ込むだけ。

  • 無音区間をミリ秒単位で自動検知
  • 「あー」「えっと」「まあ」などのフィラーをAIが識別
  • Final Cut Pro / DaVinci Resolve用のタイムラインを瞬時に生成

あとは、あなたの創造性を発揮するだけ。

JetCutterがもたらす3つの変化

編集時間を80%削減

60分動画の下準備が30分から3分に。
月に10時間の編集なら、8時間を取り戻せます。

フィラー見落としゼロ

AIによる網羅的な検知で、
人間の目が見逃すフィラーも確実にキャッチ。

創造に集中できる

単調な作業はJetCutterに任せて、
演出・構成・ストーリーテリングに時間を使いましょう。

シンプルなワークフロー

動画を選んで、ボタンを押すだけ

ファイルを選択し、出力先を指定して「処理開始」。
複雑な設定は必要ありません。

プロ向けのカスタマイズ

無音しきい値、Whisperモデル、マージン設定など
細かな調整も可能です。

詳細な分析結果

検出されたセグメントの一覧、削減率、
処理時間をひと目で確認できます。

数字で見る効果

80-90% 編集時間削減
3-5分 60分動画の処理
100% フィラー検出率

あなたのワークフローに統合

Final Cut Pro

FCPXML v1.10形式で出力。
インポートするだけでタイムライン完成。

DaVinci Resolve

Scripting APIで直接連携。
※ Studio版が必要

3ステップで始められます

1

リポジトリをクローン

git clone https://github.com/a2chub/jetcutter.git
2

依存関係をインストール

uv pip install -e ".[gui]"
3

GUIを起動

jetcutter gui

※ ffmpegが必要です: brew install ffmpeg

よくある質問

無料で使えますか？

はい、JetCutterはMITライセンスのオープンソースソフトウェアです。完全無料でお使いいただけます。

Windows/Linuxでも動きますか？

現在はmacOS向けに最適化されています。CLIはクロスプラットフォームで動作しますが、GUIはmacOS専用です。

DaVinci Resolve無料版でも使えますか？

Final Cut Pro出力（FCPXML）は無料版でも利用可能です。DaVinci Resolve直接連携にはStudio版が必要です。

フィラー辞書はカスタマイズできますか？

はい、config/fillers.yamlを編集することで、独自のフィラーワードを追加できます。

退屈な編集作業から解放されませんか？

JetCutterを使えば、今日から編集の時間を取り戻せます。
オープンソース。無料。すぐに始められます。
